### Connect Four
A simple game where you must connect four of your assigned colour of 'disc' in a a line (diagonally, vertically or horizontally). The first player to do this wins that round.


### Features
-Multiple difficulty options

-PvP functionality

-Score Tracking

-Built-in option to quit at any point


### How to Play
Compile using GCC:

    gcc C4main.c -o C4

Run using:

    ./C4
